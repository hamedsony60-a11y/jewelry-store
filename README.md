# زرنگار | فروشگاه طلا و جواهرات

سایت چندصفحه‌ای با طراحی الهام‌گرفته از iOS

## صفحات
- `index.html` — خانه
- `products.html` — محصولات + جستجو + فیلتر
- `collections.html` — مجموعه‌ها
- `contact.html` — تماس با ما

## آدرس سایت
**https://hamedsony60-a11y.github.io/jewelry-store/**

## اضافه کردن محصول
فایل `products-data.js` را ویرایش کنید و یک آبجکت جدید به آرایه `products` اضافه کنید.

## جستجو
در صفحه محصولات، کادر جستجو در بالای لیست محصولات قرار دارد و بر اساس نام، توضیحات و دسته‌بندی فیلتر می‌کند.

## درگاه پرداخت
لینک `paymentLink` هر محصول را در `products-data.js` با لینک زرین‌پال خودتان عوض کنید.
